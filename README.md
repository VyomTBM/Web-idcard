# Web-idcard
A **single-file HTML identity generator** written entirely in **Python**, lightweight and fast.

This is a **hobby project**
## Start using it!
Starting to use `Web-idcard` is simple.

**NOTE:** You don't need Python pre-installed to use Web-idcard.

You can install it by:
### CLI command
Open a **terminal client (with PowerShell)** and make sure you have **cURL** installed and run this command:
```sh
curl -o Identitygen-windows.zip "https://github.com/VyomTBM/Web-idcard/releases/download/v1.0.0/IdentityGenerator-exe.zip"
```
### Web Link
This [link](https://github.com/VyomTBM/Web-idcard/releases) will take you to the **releases page.**
